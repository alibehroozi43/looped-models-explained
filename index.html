The research story behind looped models

One model.More passes.Same weights.

Ask an AI “2 + 2?”, then ask it to fix a program. The second request needs more work. Researchers developed two powerful routes to better answers: train larger models, or generate more written reasoning steps. The first needs more model memory; the second needs more processing time.

Looping asks: what if the same layers worked again before the next piece of text? The model keeps its learned settings, called weights or parameters, and updates its temporary working state. Watch that idea in the animation.

01 / REUSE THE LAYERS

do another round?

The idea had older roots. Universal Transformers (2018) shared processing across repeated steps. Huginn (2025) explored extra internal computation in a language model.

Each round updates a temporary set of numbers, its state. Think of working notes: keep the learned method, revise the working. The number line below makes one small update visible.

What happens over four steps?

The first step takes 25% of 8, so we move to 2. There are now 6 units left. The next step takes 25% of 6, which is 1.5. We reach 3.5, not 4.

Each step uses the distance still left, so the steps get smaller.

This example shows how a pass can build on the previous state by accepting only part of a change. We chose a target of 8 for teaching; a real model does not know the correct answer in advance. The research methods below use different update rules.

See the calculation in one line
new = old + fraction × (target − old)

“Old” is your current position, “target” is 8, and “fraction” is 0.25 for a 25% step. First calculate the gap: 8 − 0 = 8. Take a quarter: 0.25 × 8 = 2. Add that move to the old position: 0 + 2 = 2. These are teaching numbers, not measurements inside Dory.

02 / MAKE THE PASSES USEFUL

Two practical problems
still had to be solved.

Extra passes alone do not guarantee better answers. Researchers needed a model that still worked well after one pass and did not cost too much to train. In 2026, ELR addressed the one-pass quality problem. The Dory paper described a full training recipe with text learning, worked examples, and scored attempts.

First, learn how text continues.

Pre-training builds basic language skills. The model reads text and predicts the next token, a short piece of text. When its prediction is wrong, training adjusts its weights so similar predictions can improve.

The sky is blue

For “The sky is …”, “blue” is one possible continuation. This builds the language foundation before teaching more useful responses. A token can be a word, part of a word, or punctuation.

Learn from examples of good answers.

Once the model can continue text, it needs practice answering requests. Supervised fine-tuning (SFT) uses questions paired with good responses. For “2 + 2 = ?”, the example answer is “4”. Training makes responses like this more likely.

The optional technical details.

Different research papers solve parts of this problem in different ways. Here are their update rules, explained symbol by symbol, followed by the original sources.

Three ways to update the model’s working notes

Take a fixed share of the change

h is the current state. The block proposes a new state, g(h). K is the chosen number of passes. Instead of jumping all the way, take 1/K of the proposed change. For h = 0, g(h) = 8, and K = 4, the next state h′ is 2. The model’s weights are frozen, meaning they are not retrained.

h′ = h + (g(h) − h) / K
[4]

Let ELR learn the size of the move

s is the current state and r is the proposed state. β tells the model how much of the change to accept. If s = 2, r = 6, and β = 0.25, the next state s′ is 3. ELR learns β during training and can use different amounts for different entries. ⊙ means multiplying matching entries. ELR also receives the pass number and the planned total, so it can learn a different update for “pass 1 of 4” and “pass 4 of 4”.

s′ = s + β ⊙ (r − s)
[3]

Keep Dory’s internal numbers on a controlled scale

x is the input written as numbers; s is the current state. Fθ is the repeated processing block and θ means its learned weights. N rescales a list of numbers to unit length, like keeping an arrow’s direction while making its length 1. First combine s and x to get u, then run the block and rescale again. s′ is the resulting state. This is not a fixed quarter-step rule.

u = N(s + x)
s′ = N(Fθ(u))
[1]
Why does the layer-execution count change?

Dory has 8 input layers, 20 shared middle layers, and 8 output layers in the model card’s count. A layer is a processing stage. Only the middle group repeats: running it twice adds 20 executions, not 20 new layers with new weights.

1 pass: 8 + 20 + 8 = 36
2 passes: 8 + 2 × 20 + 8 = 56
4 passes: 8 + 4 × 20 + 8 = 96

These numbers count stages executed, not exact seconds, energy, or new knowledge. The paper counts two smaller steps inside each layer separately, so its counts are doubled.
