# Looped Models Explained

An illustrated English–Persian research brief on how looped language models are trained, with Dory and Elastic Latent Recurrence as open examples and a careful account of public evidence on Astra.

- English by default, with a Persian language switch.
- Worked examples for depth, state updates, SFT, GRPO, and runtime.
- Interactive loop-count and partial-step illustrations.
- 16 references; reported results are distinguished from constructed examples.

Open `index.html` in a browser. The report is self-contained and does not require a build step.

## Publishing

For GitHub Pages, publish the root directory of the default branch. The `.nojekyll` file keeps the HTML as a static page.
